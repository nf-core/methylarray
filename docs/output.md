# nf-core/methylarray: Output

## Introduction

This document describes the output produced by the pipeline.

The directories listed below will be created in the results directory after the pipeline has finished. All paths are relative to the top-level results directory.

## Pipeline overview

The pipeline is built using [Nextflow](https://www.nextflow.io/) and processes data using the following steps:

- [import_idat](#import_idat) — Import raw IDAT files and build an RGChannelSet
- [raw_intensities_qc](#raw_intensities_qc) — Raw fluorescence intensity QC
- [sesame_poobah_qc](#sesame_poobah_qc) — SeSAMe normalization and pOOBAH probe masking
- [qc_report_controls](#qc_report_controls) — Illumina control probe QC report
- [snp_heatmap](#snp_heatmap) — SNP-based sample identity heatmap
- [density_plots](#density_plots) — Beta-value density plots
- [sex_qc](#sex_qc) — Predicted sex versus reported sex QC
- [filter_xy_noncg_beads](#filter_xy_noncg_beads) — Sequential probe filtering
- [cell_comp](#cell_comp) — Blood cell composition estimation
- [split_collapse](#split_collapse) — Split and collapse probe matrices for DMP/DMR
- [final_exports](#final_exports) — Final beta-value and M-value matrix exports
- [align_meta](#align_meta) — Alignment of methylation matrices with sample metadata
- [covariate_pca](#covariate_pca) — Covariate PCA and ChAMP SVD analysis
- [dmp_limma](#dmp_limma) — Differential methylation position analysis (limma)
- [dmr_dmrcate](#dmr_dmrcate) — Differential methylation region analysis (DMRcate)
- [Pipeline information](#pipeline-information) — Report metrics generated during the workflow execution

---

### `import_idat/`

Generated by the **IMPORT_IDAT** process.

This step reads raw IDAT files from `--idat_dir`, matches them to the sample sheet, and loads them into a minfi `RGChannelSet` object.

<details markdown="1">
<summary>Output files</summary>

- `rg0.rds` — Serialized R object (`RGChannelSet`) containing raw red/green channel fluorescence intensities for all samples. This is the starting point for all downstream QC and normalization steps.
- `targets.tsv` — Tab-separated targets table derived from the sample sheet, with one row per sample and columns including `Sample_Name`, `Sentrix_ID`, `Sentrix_Position`, and `Basename` (path prefix used to locate IDAT files).

</details>

---

### `raw_intensities_qc/`

Generated by the **RAW_INTENSITIES_QC** process.

Computes per-sample median red and green channel intensities from the raw `RGChannelSet` to identify samples with globally low signal, which may indicate poor hybridization or insufficient DNA input.

<details markdown="1">
<summary>Output files</summary>

- `01_plotQC_raw_intensities.png` — Scatter plot of median green versus median red channel intensities per sample. Samples below the intensity threshold are highlighted as potential failures.
- `low_intensity_samples.tsv` — Tab-separated list of samples flagged as having low raw fluorescence intensity.
- `qc_raw.tsv` — Tab-separated table of per-sample median red and green channel intensity values used to generate the QC plot.

</details>

---

### `sesame_poobah_qc/`

Generated by the **SESAME_POOBAH_QC** process.

Applies the SeSAMe preprocessing pipeline (default prep code: `QCDPB`) to the raw `RGChannelSet`. The pOOBAH (p-values with Out-Of-Band Array Hybridization) algorithm masks individual probe measurements with a detection p-value above the threshold (`--p_det`, default 0.05). Samples exceeding the allowed fraction of failed probes (`--fail_sample_fr`, default 10%) are removed; probes failing in too many samples (`--fail_probe_fr`, default 10%) are also excluded.

<details markdown="1">
<summary>Output files</summary>

- `rg_filtered.rds` — Serialized `RGChannelSet` object after removal of failed samples. Used by downstream QC steps that require channel-level data.
- `beta_norm.rds` — Serialized matrix of SeSAMe-normalized beta values (rows = probes, columns = samples) after pOOBAH masking. Values range from 0 (unmethylated) to 1 (fully methylated).
- `targets_filtered.tsv` — Targets table restricted to samples that passed pOOBAH QC, used to propagate sample metadata through subsequent steps.
- `dropped_samples.csv` — Comma-separated list of samples removed due to exceeding the maximum allowed probe failure rate, with their observed failure fractions.
- `masking_failrate_per_sample.csv` — Per-sample fraction of probes masked by pOOBAH (failed detection p-value). Useful for assessing sample-level data quality.
- `masking_failrate_per_probe.csv` — Per-probe fraction of samples in which the probe was masked by pOOBAH. Used to identify systematically failing probes.
- `02_hist_failrate_per_sample_masking.png` — Histogram of per-sample pOOBAH masking rates. Helps visualize the distribution of sample quality and the effect of the sample-level QC threshold.

</details>

---

### `qc_report_controls/`

Generated by the **QC_REPORT_CONTROLS** process.

Generates QC visualizations based on Illumina's built-in internal control probes. These probes monitor specific steps of the array chemistry (staining, hybridization, extension, bisulfite conversion, specificity, and target removal) and provide independent assessments of assay performance.

<details markdown="1">
<summary>Output files</summary>

- `00_qcReport.pdf` — Comprehensive PDF QC report produced by minfi's `qcReport()` function, summarizing control probe performance and overall sample quality metrics.
- `00_controlStrip_STAINING.png` — Strip plot of staining control probe intensities per sample, assessing the efficiency of the labeling step.
- `00_controlStrip_EXTENSION.png` — Strip plot of extension control probe intensities, assessing nucleotide incorporation efficiency.
- `00_controlStrip_HYBRIDIZATION.png` — Strip plot of hybridization control probe intensities, assessing oligonucleotide binding performance.
- `00_controlStrip_TARGET_REMOVAL.png` — Strip plot of target removal control probe intensities, assessing the efficiency of post-extension stripping.
- `00_controlStrip_SPECIFICITY_I.png` — Strip plot of Type I specificity control probes, assessing single-base extension specificity.
- `00_controlStrip_SPECIFICITY_II.png` — Strip plot of Type II specificity control probes, assessing specificity of the Type II assay chemistry.
- `00_controlStrip_NON_POLYMORPHIC.png` — Strip plot of non-polymorphic control probe intensities, providing a reference for expected signal levels regardless of sample genotype.
- `00_controlStrip_NEGATIVE.png` — Strip plot of negative control probe intensities, used to estimate background signal levels.
- `03_control_bisulfite_I.png` — Bisulfite conversion efficiency plot for Type I probes. Low conversion efficiency indicates incomplete bisulfite treatment, which inflates beta values for unmethylated CpGs.
- `04_control_bisulfite_II.png` — Bisulfite conversion efficiency plot for Type II probes.

</details>

### `snp_heatmap/`

Generated by the **SNP_HEATMAP** process.

Uses the 59 SNP-probes on the EPIC array (designed to detect common genetic variants) to compute pairwise sample correlations. High correlation between nominally distinct samples indicates potential sample duplication, swap, or contamination.

<details markdown="1">
<summary>Output files</summary>

- `05_heatmap_snp_correlation.png` — Hierarchically clustered heatmap of pairwise Pearson correlations between samples based on SNP probe beta values. Unexpected high correlations between different samples indicate potential identity issues.

</details>

---

### `density_plots/`

Generated by the **DENSITY_PLOTS** process.

Visualizes the distribution of beta values across all probes for each sample, before and after SeSAMe normalization. Well-normalized methylation data typically show a bimodal distribution with peaks near 0 (unmethylated) and 1 (fully methylated).

<details markdown="1">
<summary>Output files</summary>

- `06_density_beta_raw.png` — Overlay density plot of raw (pre-normalization) beta values for all samples. Used to identify outlier samples with aberrant methylation distributions.
- `07_density_beta_sesame.png` — Overlay density plot of SeSAMe-normalized beta values. Comparison with the raw plot shows the effect of normalization and identifies any persistent outliers.

</details>

---

### `sex_qc/`

Generated by the **SEX_QC** process.

Predicts biological sex from methylation data using median X and Y chromosome intensities and compares predictions against the reported sex in the metadata file. Discordances may indicate sample swaps, sex chromosome abnormalities, or metadata errors.

<details markdown="1">
<summary>Output files</summary>

- `08_plotSex_predicted.png` — Scatter plot of median Y chromosome intensity versus median X chromosome intensity per sample, with predicted sex colour-coded. Expected clusters correspond to XX (female) and XY (male) genotypes.
- `qc_predicted_sex.csv` — Comma-separated table with one row per sample containing the predicted sex, median X and Y intensities, and the reported sex from metadata. Used in the metadata alignment step.
- `sex_discordant_samples.csv` — Comma-separated list of samples where predicted sex does not match reported sex, flagged for manual review.

</details>

---

### `filter_xy_noncg_beads/`

Generated by the **FILTER_XY_NONCG_BEADS** process.

Applies two sequential probe filters to the normalized beta matrix:

1. Sex-chromosome probes (chrX and chrY) are removed to avoid sex-driven confounding in autosomal analyses (controlled by `--filter_xy`).
2. Non-CpG probes (probes not starting with `cg`) are removed to restrict analysis to canonical CpG methylation (controlled by `--filter_noncg`).

Bead count masking (minimum 3 beads per probe) is applied upstream by SeSAMe's `qualityMask` (Q step) during normalisation in `SESAME_POOBAH_QC`.

<details markdown="1">
<summary>Output files</summary>

- `beta3.rds` — Serialized R matrix of beta values after all three filtering steps have been applied. This is the primary input for cell composition estimation, split/collapse, and downstream analysis.
- `filtering_summary.tsv` — Tab-separated table recording the number of probes and samples at each filtering stage: input, after pOOBAH present-call filter, after XY removal, after non-CpG removal, and after bead-count filtering. Example from a representative run:

  | stage             | n_probes | n_samples | dropped_xy | dropped_noncg | dropped_beads |
  | ----------------- | -------- | --------- | ---------- | ------------- | ------------- |
  | input_beta_norm   | 889,036  | 96        | —          | —             | —             |
  | after_present     | 888,224  | 96        | —          | —             | —             |
  | after_drop_xy     | 867,286  | 96        | 20,938     | —             | —             |
  | after_drop_non_cg | 864,089  | 96        | —          | 3,197         | —             |
  | after_drop_beads  | 862,281  | 96        | —          | —             | 1,808         |
  | final_beta3       | 862,281  | 96        | —          | —             | —             |

</details>

### `cell_comp/`

Generated by the **CELL_COMP** process (when `--do_estimate_cellcomp true`, which is the default).

Estimates the proportions of major blood cell types in each sample using the Houseman reference-based deconvolution algorithm implemented in the `FlowSorted.Blood.EPIC` Bioconductor package. Cell composition estimates can be included as covariates in DMP/DMR models to control for cellular heterogeneity.

<details markdown="1">
<summary>Output files</summary>

- `cell_counts_blood.csv` — Comma-separated matrix of estimated cell-type proportions with one row per sample and one column per cell type: `CD8T`, `CD4T`, `NK`, `Bcell`, `Mono`, `Neu`, `Gran`.

</details>

---

### `split_collapse/`

Generated by the **SPLIT_COLLAPSE** process.

Prepares two separate beta-value matrices optimized for DMP and DMR analyses respectively. For DMP analysis, EPICv2 positional replicate probes are collapsed according to the `--posreps_strategy` parameter (default: `mean`). For DMR analysis, probes are optionally remapped to unique genomic coordinates for use with DMRcate (`--epicv2_remap`).

<details markdown="1">
<summary>Output files</summary>

- `beta_clean.rds` — Serialized beta-value matrix with EPICv2 positional replicates collapsed (for DMP analysis). This is the input for final matrix exports and metadata alignment.
- `beta_for_DMR_uncollapsed.rds` — Serialized beta-value matrix with probes remapped to EPICv2 unique coordinates but not collapsed, intended for DMRcate regional analysis where probe-level spatial resolution is required.

</details>

---

### `final_exports/`

Generated by the **FINAL_EXPORTS** process.

Produces the final, analysis-ready methylation matrices and associated manifests from the collapsed beta matrix.

<details markdown="1">
<summary>Output files</summary>

- `bVals_final.rds` — Serialized R matrix of final beta values (rows = probes, columns = samples). Beta values range from 0 to 1 and represent the proportion of methylated molecules at each CpG. Suitable for visualization and models where interpretability is important.
- `mVals_final.rds` — Serialized R matrix of final M-values (log2 ratio of methylated to unmethylated signal). M-values are statistically preferred for linear models (homoscedastic) and are used as input for DMP analysis.
- `probes_final.csv` — Comma-separated manifest of probes retained in the final matrices, including probe identifiers and annotation columns.
- `samples_final.csv` — Comma-separated manifest of samples retained in the final matrices, including sample identifiers and basic metadata carried through from the targets table.
- `qc_summary.txt` — Plain-text summary of key QC metrics accumulated across the pipeline, including sample counts at each QC stage and final probe/sample dimensions.

</details>

---

### `align_meta/`

Generated by the **ALIGN_META** process.

Joins the final methylation matrices (bVals, mVals) with the user-supplied metadata, predicted sex from the sex QC step, and estimated cell composition proportions. Only samples present in all three sources are retained for downstream analysis. The resulting aligned objects are the primary inputs for PCA, DMP, and DMR analysis.

<details markdown="1">
<summary>Output files</summary>

- `bVals_aligned.rds` — Serialized beta-value matrix subset and column-ordered to match the aligned metadata. Column names correspond to `sample_id` values.
- `mVals_aligned.rds` — Serialized M-value matrix subset and column-ordered to match the aligned metadata.
- `meta_aligned.csv` — Comma-separated metadata table containing all samples that passed QC and were successfully matched across the samplesheet, metadata file, sex predictions, and cell composition estimates. This file includes all original metadata columns plus appended predicted sex and cell composition columns.
- `bVals_unmapped_colnames.csv` — Comma-separated list of sample column names present in the beta matrix that could not be matched to the metadata. Useful for diagnosing sample ID mismatches between the samplesheet and metadata file.

</details>

---

### `covariate_pca/`

Generated by the **COVARIATE_PCA** process (when `--run_covariate_pca true`, which is the default).

Performs principal component analysis (PCA) on the aligned beta-value matrix and tests for statistical associations between the top principal components and sample covariates. Also runs ChAMP's SVD analysis, which uses singular value decomposition to identify major axes of variation and their covariate correlates.

<details markdown="1">
<summary>Output files</summary>

- `covariates_PC_association_minuslog10p.csv` — Comma-separated matrix of -log10(p-values) from linear model tests of association between each PC (rows) and each covariate in the metadata (columns). Useful for identifying technical or biological sources of variation captured by the principal components.
- `covariate_checks.txt` — Plain-text report summarizing the covariate-PC associations, including the variance explained by each PC and a flag for any PC showing unexpectedly strong association with technical variables such as `Plate`.
- `ChAMP_SVD/` — Subdirectory for outputs of ChAMP's `champ.SVD()` function. May contain SVD heatmaps and covariate correlation results if the analysis completes successfully.

</details>

---

### `dmp_limma/`

Generated by the **DMP_LIMMA** process (when `--run_dmp true`, which is the default).

Runs pairwise differential methylation position (DMP) analysis using the limma framework. M-values are used as the response variable. All pairwise contrasts between groups defined in the `group` metadata column are tested, with `CONTROL` as the reference level. The analysis is run under three covariate adjustment strategies, each producing its own subdirectory:

- `DMP_limma__norm_only/` — Model includes `age`, `sex`, `bmi`, and cell composition covariates only (no batch correction).
- `DMP_limma__plate_in_model/` — Model additionally includes `Plate` as a fixed-effect covariate.
- `DMP_limma__combat/` — ComBat batch correction is applied to M-values using `Plate` as the batch variable before fitting the limma model.

Each subdirectory contains the same set of files:

<details markdown="1">
<summary>Output files (per subdirectory)</summary>

- `DMP_<GroupA>_vs_<GroupB>.csv` — Comma-separated limma results table for the contrast GroupA versus GroupB. Columns include probe ID, log-fold-change in M-value (`logFC`), average M-value (`AveExpr`), moderated t-statistic (`t`), unadjusted p-value (`P.Value`), Benjamini-Hochberg adjusted p-value (`adj.P.Val`), and B-statistic (`B`). One file is produced per pairwise contrast.
- `DMP_summary_counts_and_lambda.csv` — Comma-separated summary table with one row per contrast, reporting the number of significant DMPs (at FDR < 0.05 and |delta-beta| thresholds) and the genomic inflation factor lambda, which can indicate p-value inflation due to uncontrolled confounding.
- `meta_used.csv` — Comma-separated metadata table as actually used in the limma model for this analysis mode, after any ComBat correction or covariate adjustment. Useful for verifying which samples and covariates were included.
- `SVA_k_selection.csv` — (Present in `combat` mode only) Comma-separated table recording the number of surrogate variables estimated or the ComBat parameters applied during batch correction.

</details>

---

### `dmr_dmrcate/`

Generated by the **DMR_DMRCATE** process (when `--run_dmr true`, which is the default).

Runs pairwise differential methylation region (DMR) analysis using the DMRcate package. Beta values from the uncollapsed, EPICv2-remapped matrix are used. DMRcate identifies genomic regions where multiple nearby CpGs show consistent differential methylation. All pairwise contrasts between groups are tested under the same three adjustment strategies as the DMP analysis:

- `DMR_DMRcate_EPICv2__norm_only/`
- `DMR_DMRcate_EPICv2__plate_in_model/`
- `DMR_DMRcate_EPICv2__combat/`

Each subdirectory contains the same set of files:

<details markdown="1">
<summary>Output files (per subdirectory)</summary>

- `DMRcate_<GroupA>_vs_<GroupB>_ranges.csv` — Comma-separated table of identified DMRs for the contrast GroupA versus GroupB. Columns include genomic coordinates (`seqnames`, `start`, `end`), the number of CpGs in the region (`no.cpgs`), minimum FDR across constituent CpGs (`min_smoothed_fdr`), mean delta-beta across the region (`meandiff`), and the Stouffer combined p-value for the region (`Stouffer`). One file is produced per pairwise contrast.
- `DMRcate_summary_nDMR_per_contrast.csv` — Comma-separated summary table reporting the number of significant DMRs (at FDR < 0.05) identified in each pairwise contrast.
- `meta_used.csv` — Comma-separated metadata table as used in the DMRcate model for this analysis mode.
- `SVA_k_selection.csv` — (Present in `combat` mode only) ComBat batch correction parameters applied before DMRcate analysis.

</details>
